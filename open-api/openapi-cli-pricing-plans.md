# CLI & MCP Plans

UniSat offers flexible API plans for different usage needs, from individual development and testing to large-scale applications. Choose **MCP & CLI Pricing** when you use UniSat OpenAPI through the CLI or an MCP-compatible AI agent. **Base Pricing** is available separately for other API usage.

## How to select a plan

1. Visit the [UniSat API Pricing page](https://unisat.io/open-api/plans).
2. In the top-right corner, select **MCP & CLI Pricing**.
3. Choose **Monthly** or **Yearly** billing to view the available subscription options.
4. Review the plans and select the one that best fits your request volume, rate limits, infrastructure, and support needs.
5. Select **Get Started** to continue with a paid plan, or **Get Your Free API Key** to start with the Free plan.

### Plans for different needs

| Plan | Best for | Key features |
| --- | --- | --- |
| Free | Evaluation, research, testing, and small projects | No subscription required, with limited daily requests and request rate |
| Specialist | Independent developers, larger scripts, and growing projects | Higher request limits, shared infrastructure, and basic email support |
| Enterprise | Wallets, exchanges, project teams, and high-volume applications | Higher request limits, dedicated infrastructure and SLA, and priority support |
| Custom Plan | Projects with specific business, deployment, or infrastructure requirements | Custom request limits, flexible infrastructure and deployment options, and dedicated support |
| Pay as You Go | Flexible or temporary usage needs | Purchase additional API calls as needed without a recurring subscription |

## Usage limits and billing

Each plan has its own request limits and pricing structure:

- **Daily request limit:** The maximum number of API calls allowed per day.
- **Rate limit:** The maximum number of API calls allowed per second.
- **Subscription plans:** Monthly and yearly billing options are available for supported plans.
- **Pay as You Go:** Purchase additional API calls based on your usage needs.

Request limits, pricing, and available features vary by plan. Refer to the [UniSat API Pricing page](https://unisat.io/open-api/plans) for current values.
