# OpenAPI CLI & MCP

UniSat AI Kit makes it easier to explore on-chain data, analyze assets, and build applications using AI agents. Simply describe what you need in natural language, and let your agent interact with UniSat Open API through CLI or MCP.

CLI brings UniSat Open API into your terminal, scripts, and AI coding environments. Query on-chain data, run batch operations, and automate repetitive tasks as part of your development workflow.

MCP connects compatible AI clients to UniSat Open API through a local MCP server. Your AI assistant can access on-chain balances, asset holdings, transactions, and more, using real data to complete tasks and answer questions.

Both provide access to the same UniSat Open API capabilities across Bitcoin and Fractal Bitcoin mainnet, with separate API keys for each network.
