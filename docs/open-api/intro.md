# Open API Documentation

Welcome to the UniSat Open API documentation. This section contains guides and API references for UniSat Open API services.

## Request Base URLs

Choose the base URL for your network and append the endpoint path. Supported networks vary by endpoint.

| Chain | Network | Base URL |
| --- | --- | --- |
| Bitcoin | Mainnet | `https://open-api.unisat.io` |
| Bitcoin | Testnet4 | `https://open-api-testnet4.unisat.io` |
| Bitcoin | Signet | `https://open-api-signet.unisat.io` |
| Fractal Bitcoin | Mainnet | `https://open-api-fractal.unisat.io` |
